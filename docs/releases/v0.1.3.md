# FrameRec 0.1.3

首次提供可直接下载的 macOS 通用版应用，无需安装 Xcode、Python 或其他开发工具。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| [FrameRec-0.1.3-macOS-universal.dmg](https://github.com/xiuleitan/FrameRec/releases/download/v0.1.3/FrameRec-0.1.3-macOS-universal.dmg) | 推荐下载；打开后将 FrameRec.app 拖到 Applications（应用程序） |
| [FrameRec-0.1.3-macOS-universal.zip](https://github.com/xiuleitan/FrameRec/releases/download/v0.1.3/FrameRec-0.1.3-macOS-universal.zip) | 备用下载；解压后将 FrameRec.app 拖到“应用程序” |
| [SHA256SUMS.txt](https://github.com/xiuleitan/FrameRec/releases/download/v0.1.3/SHA256SUMS.txt) | 上述两个安装包的 SHA-256 校验值 |

- 系统要求：macOS 14 或更高版本。
- 架构：Apple 芯片（arm64）和 Intel（x86_64），同一个包内包含两个架构。
- 应用界面：中文。
- 应用常驻菜单栏，启动后点击取景框图标使用。
- 更新已有安装时，请先退出旧版，再替换应用。
- GitHub 自动附带的 `Source code` 文件为源码，无需下载它们来安装应用。

## 首次打开与录屏权限

**当前版本使用固定的本地签名，尚未使用 Apple Developer ID 签名或经过 Apple 公证。**

如果 macOS 提示无法验证开发者或无法检查恶意软件，请先确认安装包来自本仓库。尝试打开后，进入“系统设置 → 隐私与安全性”，找到 FrameRec 的提示并点击“仍要打开”，再按系统提示确认。受组织管理的 Mac 可能限制此选项。详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

首次开始录屏时，还需要在“隐私与安全性 → 屏幕与系统音频录制”中允许 FrameRec；必要时完全退出并重新打开应用。FrameRec 不请求或使用麦克风。

## 功能

- 可调整的区域录屏，支持多显示器。
- MP4 / MOV，24 / 30 / 60 帧，可选择是否显示鼠标指针。
- 录制系统内部声音，暂停时间不进入成片。
- 菜单栏入口和可自定义全局快捷键。
- 自动保存、历史搜索、重命名、预览和导出副本。
- 时间轴区间删除、逐帧定位、撤销和音画同步剪除。
- 0.1.3 复用固定签名身份，修复本地构建更新后授权身份变化的问题。

**历史录屏在录制完成 30 天后自动清理。需要长期保留的录屏，请使用“导出副本”。** 默认目录为 `~/Movies/FrameRec`，可在设置中修改。

## 发布验证范围

- 23 项现有 Swift 测试通过。
- arm64 / x86_64 两个架构编译通过，最低系统版本标记均为 macOS 14.0。
- 应用双架构代码签名、ZIP 解压后的代码签名和 DMG 校验通过。

## English

Download the universal DMG, open it, and drag FrameRec.app to Applications. The ZIP is an alternative. Requires macOS 14 or later and includes both Apple Silicon and Intel executables. No development tools are needed; the app UI is in Chinese.

This release uses a local signature and has no Apple Developer ID signature or Apple notarization. If the first launch is blocked, verify the download source and follow [Apple's instructions](https://support.apple.com/en-us/102445) to use Open Anyway in System Settings > Privacy & Security. Screen & System Audio Recording permission is also required before recording.

History recordings are automatically cleaned up after 30 days. Use Export Copy to keep them long term. The 23 tests and archive checks passed; launch was checked on Apple Silicon, while Intel hardware and macOS 14 / 15 remain untested.
